# 🌍 Personal World

موقع هدية شخصي — Next.js + Supabase + Tailwind.

المشروع دلوقتي فيه **كل المراحل السبعة** من الفكرة الأصلية:

- **الأساس**: تسجيل دخول/حساب حقيقي، **نسيت كلمة السر** (استرجاع بالإيميل)، رسالة ترحيب مرة واحدة، Dark/Light Mode، دعم كامل للعربي RTL
- **تصميم مبهر**: خلفية Aurora متدرجة، بطاقات بظلال ناعمة وanimations سلسة (framer-motion)، حلقة تقدم دائرية متحركة، **Command Palette** (⌘K / Ctrl+K)، شاشات تحميل Skeleton أنيقة، وToast notifications بدل رسائل المتصفح العادية
- **حماية من الأخطاء**: تأكيد قبل أي حذف (مهمة، عادة، هدف، ذكرى، حدث...)، صفحة 404 وصفحة خطأ مصممتين بهوية الموقع، وتنبيه لما الإنترنت يقطع أو يرجع
- **أمان مراجَع بعمق**: خصوصية خاصة افتراضيًا، Views آمنة تمنع أي تسريب بيانات عن طريق الـ API مباشرة، موافقة حقيقية ثنائية على المشاركة مع شخص تاني (مش مجرد ربط تلقائي)، كلمة سر 8 أحرف كحد أدنى
- **روابط ذكية**: أي مهمة/هدف/عنصر في "عالمي"/ذكرى/موعد ممكن يتحط له رابط — لينك يوتيوب بيتشغّل جوه الموقع نفسه (بكل أدوات المشغّل بما فيها تغيير السرعة)، وأي رابط تاني بيتفتح في تاب جديد
- **مزامنة مع Google Calendar**: زرار في `/calendar` لربط الحساب ورفع المواعيد مباشرة لتقويم Google بتاعه (اختياري، يحتاج إعداد بسيط من Google Cloud — تفاصيله تحت)
- **حجم الخط**: تحكم في حجم خط الموقع كله من `/settings` (إمكانية وصول لمن يحتاج خط أكبر)
- **🎯 Focus Mode**: يختار مهمة من Top 3 ويدخل وضع تركيز كامل الشاشة (بومودورو 25/5، 50/10، أو مخصّص) يخفي كل حاجة تانية، وينتهي بـ"Done. One thing less."
- **🌤️ حاسس إزاي النهاردة؟**: سؤال بسيط صباحي، بينعكس في جملة لطيفة واحدة — مفيش تحليل أو حكم، مجرد انعكاس
- **🧹 ضبط يوم جديد**: صفحة `/reset` تراجع مهام إمبارح (خلصت/لسه) وتنقل الناقص لـ Top 3 النهاردة بضغطة، بدل ما يتراكم
- **⭐ أشياء عايز أفتكرها**: قسم داخل اليوميات للحظات المميزة (مش يوميات عادية) مع صورة، وبتفاجئه تلقائيًا بعد سنة
- **تصميم "التركيز على النهاردة"**: الداشبورد بيوريه بس المهم دلوقتي (Top 3، مواعيد النهاردة، عاداته، فكرة اليوم) — الباقي كله موجود لما يحتاجه، مش مكدّس قدامه
- **احتفالات صغيرة**: كونفيتي حقيقي لما يخلّص Top 3 بالكامل، وكارت "من سنة في نفس اليوم ده" لو كتب يوميات في نفس التاريخ ده من سنة فاتت
- **شخصي أكتر**: صورة شخصية حقيقية (رفع على Supabase Storage)، وصور لكل ذكرى في `/timeline`
- **🎂 مفاجأة عيد الميلاد**: يوم 11 أكتوبر بالظبط، شاشة "Happy Birthday, Ahmed" بألعاب نارية حقيقية (Canvas)، تظهر مرة واحدة كل سنة تلقائيًا
- **🤝 مشاركة مع شخص تاني**: `/partner` — ربط الحساب بحساب شخص تاني بكود، وشوف تقدم بعض في الأهداف/المهام اللي حددتوها كـ "مشتركة"
- **تحكم كامل في الخصوصية**: كل حاجة **خاصة افتراضيًا** — كل عنصر (اهتمام، حاجة في "عالمي"، حاجة في "حاليًا") له زرار 🌐 عام / 🔒 خاص مستقل، وهو اللي يختار بنفسه إيه اللي يشاركه، ومركز خصوصية في `/settings` يلخّص كل حاجة عامة دلوقتي
- **عالمه الشخصي**: `/about` (عني)، `/interests` (اهتماماتي)، `/world` (موسيقى/أفلام/كتب/بودكاست/أماكن/هوايات)، Currently في الداشبورد
- **الإنتاجية**: `/dashboard` (Top 3 + حلقة تقدم اليوم + مواعيد النهاردة)، `/tasks` (مهام بأولويات، فيها خيار "مشتركة"، والمتأخرة بتظهر باللون الأحمر)، `/calendar` (مخطط شهري كامل بالمواعيد + تصدير لملف .ics يضاف لتقويم الموبايل)
- **النمو**: `/habits` (عادات وStreaks)، `/goals` (أهداف أسبوعية/شهرية بـ Progress Bar، فيها خيار "مشترك مع شخص تاني")، `/review` (مراجعة يومية ومراجعة أسبوعية)
- **اللمسة الشخصية**: `/journal` (يوميات/ملاحظات/اقتباسات/حاجات تعلمها)، `/timeline` (ذكريات بالسنين والصور)، `/messages` (رسائل مفاجئة تظهر تلقائيًا حسب شرط: بعد X يوم، في تاريخ معين، أو أول ما يحقق هدف)
- **الترحيل والنسخ الاحتياطي**: تصدير كامل JSON (استرجاع كامل)، وتصدير Markdown منظّم جاهز للاستيراد في Notion أو Obsidian أو أي أداة تانية — البيانات ملكه دايمًا، مش حبيسة
- **المتقدم**: بحث موحّد (`/search`) بيغطي المهام والأهداف والمواعيد والذكريات والملاحظات وعالمي والاهتمامات كلهم مع بعض، زرار "شارك يومي" (نسخ/مشاركة جدول اليوم)، PWA (يتثبت كـ App)، تذكيرات محلية بالمتصفح (Notification API)
- **صفحة عامة اختيارية**: `/u/[username]` — رابط تقدر تشاركيه لأي حد بدون تسجيل دخول، يعرض بس العناصر اللي حددتها كـ 🌐 عام

## 1. تجهيز Supabase (قاعدة البيانات + تسجيل الدخول)

1. اعملي حساب على https://supabase.com (مجاني).
2. اعملي **New Project**. هتاخد كلمة سر لقاعدة البيانات — احفظيها.
3. لما المشروع يخلص إنشاء (بيستغرق دقيقة أو دقيقتين)، روحي على:
   **Project Settings → API**
   وهتلاقي فيها:
   - `Project URL` → دي قيمة `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public` key → دي قيمة `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. روحي على **SQL Editor → New query**، وافتحي ملف `supabase/schema.sql` من المشروع ده، انسخي كل محتواه، حطيه في الـ Editor، واضغطي **Run**.
   ده هيعمل كل الجداول (profiles, tasks, events, habits, goals, notes...)، حماية البيانات (كل شخص يشوف بياناته بس)، وكمان بيجهّز مكانين لتخزين الصور (الصورة الشخصية وصور الذكريات) تلقائيًا.
5. (اختياري لكن مفيد الآن) في **Authentication → Providers**، تأكدي إن **Email** مفعّل (بيكون مفعّل افتراضيًا).
6. في **Authentication → URL Configuration**، لما ترفعي الموقع على Vercel هتضيفي رابط الموقع في **Site URL**، وفي **Redirect URLs** ضيفي `https://رابط-موقعك/reset-password` (ده لازم عشان رابط "نسيت كلمة السر" يشتغل صحيح). وعشان تجربيها محليًا كمان، ضيفي `http://localhost:3000/reset-password`.

## 2. تشغيل المشروع على جهازك

محتاجة [Node.js](https://nodejs.org) نسخة 18 أو أحدث مُنصّبة.

```bash
cd personal-world
npm install
cp .env.example .env.local
```

افتحي `.env.local` وحطي فيه قيم Supabase:

```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```

> اسمه (أحمد حمزة) متسجل بالفعل كقيمة افتراضية في `schema.sql`، فأول حساب هيتعمل هيظهر له اسمه في التحية ورسالة الترحيب تلقائيًا — مفيش حاجة تانية تعمليها. لو حبيتي تغيّريه، من `/settings` بعد تسجيل الدخول.

بعد كده:

```bash
npm run dev
```

وافتحي المتصفح على: http://localhost:3000

هيوجّهك على صفحة تسجيل الدخول. اعملي حساب (Sign up) بإيميل حقيقي أو حتى إيميل تجربة، وسجّلي دخولك، وهتشوفي رسالة الترحيب أول مرة، وبعدها الـ Dashboard.

> ملحوظة: Supabase ببعت إيميل تأكيد بعد التسجيل. تقدري تعدّلي ده من
> **Authentication → Providers → Email → Confirm email** (تقفليها وقت التطوير لو حابة تسجيلي دخول فورًا بدون تأكيد).

### ⚠️ قبل ما ترفعي على GitHub/Vercel

المشروع كبير (أكتر من 130 ملف)، وأنا بنيته من غير ما أقدر أشغّله فعليًا في بيئة حقيقية. قبل النشر، شغّلي الأمر ده في نفس مجلد المشروع:

```bash
npm run build
```

لو طلع أي خطأ (Error باللون الأحمر)، انسخيه وابعتهولي وهساعدك تحليه فورًا. لو خلص من غير أخطاء (يقولك "Compiled successfully")، يبقى المشروع جاهز للنشر بأمان.

```bash
cd personal-world
git init
git add .
git commit -m "Personal World - Phase 1 & 2 foundation"
```

بعدين اعملي repository جديد فاضي على GitHub (بدون README)، وهيديكي أوامر زي دي — نفذيها:

```bash
git remote add origin https://github.com/USERNAME/personal-world.git

git push -u origin main
```

(ملف `.env.local` مش هيترفع أبدًا — محمي في `.gitignore` — عشان مفاتيح Supabase تفضل سرية.)

## 4. النشر على Vercel

1. اعملي حساب على https://vercel.com وسجّلي دخول بـ GitHub.
2. **Add New → Project**، واختاري الـ repository اللي رفعتيه.
3. في خطوة **Environment Variables**، ضيفي نفس القيم اللي في `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. اضغطي **Deploy**. بعد دقيقة أو اتنين هيديكي رابط زي:
   `https://personal-world-xxxx.vercel.app`
5. رجعي لـ Supabase → **Authentication → URL Configuration**، وضيفي الرابط ده في **Site URL** و **Redirect URLs**.

الموقع دلوقتي شغال حقيقي على الإنترنت. 🎉

> **Railway** بديل لـ Vercel لو حبيتي، خطواته مشابهة: اربطي الـ GitHub repo، ضيفي متغيرات البيئة نفسها، والمشروع Next.js شغال عليها برضو. Vercel عمومًا أسهل وأسرع لمشاريع Next.js.

## 5. ربط Google Calendar (اختياري)

ده مش شرط عشان الموقع يشتغل — الموقع شغال بدونه 100%، وده بس لو حابة زرار "مزامنة مع Google Calendar" في صفحة المخطط يكون فعّال.

1. روحي على https://console.cloud.google.com وسجّلي دخول بحساب Google.
2. اعملي مشروع جديد (أو استخدمي أي مشروع موجود).
3. من القائمة الجانبية: **APIs & Services → Library**، دوّري على **Google Calendar API** وفعّليها.
4. **APIs & Services → OAuth consent screen**: اختاري **External**، واملي الاسم والإيميل بتاعك بس (كفاية).
5. **APIs & Services → Credentials → Create Credentials → OAuth client ID**:
   - Application type: **Web application**
   - في **Authorized JavaScript origins** ضيفي رابط موقعك على Vercel (مثلاً `https://personal-world-xxxx.vercel.app`) وكمان `http://localhost:3000` للتجربة المحلية
   - مفيش داعي لأي Redirect URI هنا
6. هيديكي **Client ID** (شكله زي `123456-abc.apps.googleusercontent.com`) — انسخيه وحطيه في `.env.local` وفي Environment Variables بتاعة Vercel:
   ```
   NEXT_PUBLIC_GOOGLE_CLIENT_ID=123456-abc.apps.googleusercontent.com
   ```

> **ملحوظة مهمة**: المزامنة دي "رفع" (Push) مش "مزامنة تلقائية مستمرة" — يعني كل مرة يفتح فيها صفحة المخطط ويضغط "مزامنة الآن"، المواعيد الجديدة بترفع لتقويم Google بتاعه. الربط بيفضل شغال لمدة الجلسة (حوالي ساعة)، وبعدها لو حب يزامن تاني هيضغط "ربط" تاني بضغطة واحدة بسيطة. لو عايزة مزامنة تلقائية في الخلفية بدون أي تدخل منه خالص، ده يحتاج سيرفر إضافي يشتغل باستمرار — تقدري تطلبيه في أي وقت لو حسيتي إنه محتاجه فعليًا.

## 6. أيقونات الـ PWA (اختياري لكن يفضل)

عشان الموقع يظهر بأيقونة حقيقية لما يتثبت على الموبايل، حطي صورتين في `public/`:
- `icon-192.png` (192×192)
- `icon-512.png` (512×512)

أي صورة مربعة بسيطة (حتى لو حرف أو رمز) هتشتغل. من غيرهم الموقع لسه شغال عادي، بس بأيقونة افتراضية.

## 7. التسليم النهائي

لما تخلصي كل حاجة وتكوني جاهزة تسلّمي الموقع فعليًا:
1. راجعي `SECURITY_CHECKLIST.md` كامل (اختبارات أمان مهمة قبل أي تسليم).
2. اتبعي `HANDOVER.md` لخطوات نقل الملكية بالتفصيل.
3. افتحي `/handover` في الموقع نفسه (وانتي لسه مسجّلة دخول) — فيها checklist تفاعلية ولمسة تسليم نهائية. الصفحة دي مش موجودة في القوائم عن قصد، تفتحيها بالرابط المباشر بس.
